一頁結論

  • 核心判斷：華通已從手機 HDI 供應鏈轉向「低軌衛星＋AI 資料中心高速互連」雙引擎；方向偏多，但 248 元已約反映 2027 EPS 共識的 18.9 倍，必須靠毛利率與 EPS 躍升兌現。
  • 最重要催化劑：2026Q4–2027Q1 V3 衛星板量產，以及 800G／1.6T 光模組 mSAP 板放量。
  • 最大反證風險：V3 轉換延遲、CCL／玻纖布缺料、巨額資本支出帶來折舊，而高毛利新品未改善獲利。
  • 市場可能尚未充分反映：若資料中心占比與 mSAP 毛利結構快速上升，2027 EPS 的非線性成長仍可能被低估。

Layer 2｜市場共識

多方論點

V3 衛星板層數與材料升級提高單顆價值；800G／1.6T mSAP 製程門檻與毛利高於公司均值；泰國與台灣／重慶擴產提供非中產能及大規模供應能力。

空方論點

Layer 3｜反共識推理

市場可能低估

市場若仍用手機 HDI 週期股框架評價，可能低估衛星與資料中心板在規格、認證與良率上的門檻，以及高階產品占比上升對毛利率的槓桿。

市場可能高估

營收占比提升不等於獲利同步提升；擴產先帶來現金流與折舊負擔，V3 客戶部署與光模組需求也可能延後。

條件式策略與風險

  • 觀察條件：月營收、毛利率、衛星／資料中心占比、CAPEX 與折舊。
  • 可能建倉條件：回檔守穩 60 日線，EPS 共識未下修且 V3 量產證據增強。
  • 加碼條件：毛利率與 EPS 同步上修，而非僅營收創高。
  • 降低曝險／停損條件：跌破 60 日線且伴隨共識下修或 V3 延遲。
  • 基本面失效條件：高階新品占比上升但毛利率連兩季惡化。
