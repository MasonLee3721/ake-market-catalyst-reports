一頁結論

  • 核心判斷： 松崗是「資訊服務＋資產管理」的小型轉機／資產股。本業毛利率與營業利益已有改善，但業外損失仍主導EPS，轉機尚未閉環。
  • 最重要催化劑： 2026Q3財報能否證明本業連續獲利、生命／寵物／高球數位化專案能否擴大非關係人營收，以及資產投資損益能否止穩。
  • 最大反證風險： 客戶集中、專案型營收波動、業外投資評價及低流動性價格波動。
  • 市場可能尚未充分反映： 若資訊服務規模成長並維持50%以上毛利率，本業損益有槓桿；但10月20日漲停已先反映轉機想像，而9月營收與H1 EPS尚未支持成熟成長敘事。

Layer 2｜市場共識

多方論點

1. 2026H1毛利率升至52.78%，營業利益66.5萬元，顯示本業由虧轉盈的早期跡象。

2. 資訊服務聚焦生命事業、寵物、高球及OMO／CDP等垂直數位化，具小型利基市場想像。

3. 資產管理若產生處分利益或評價回升，對小型損益表可能形成高彈性。

4. 股價已站上主要均線，籌碼短線偏強。

空方論點

1. 2026前九月營收只年增0.21%，9月單月更年減26.44%，尚無持續成長證據。

2. 2026H1其他利益及損失為-1,556.8萬元，使本業小幅獲利無法轉化為淨利。

3. UAnalyze所述生命事業關係人客戶集中度高，若專案遞延，營收與回款可能劇烈波動；此項需以年報關係人揭露持續核對。

4. 目前沒有2026F以後可靠法人預估；在EPS為負時，本益比不具解釋力。

Layer 3｜反共識推理

市場可能低估

市場可能只看到EPS虧損，低估2026H1毛利率由40.92%升至52.78%、營業損益由-446.5萬元改善至+66.5萬元的本業轉折。如果資訊服務收入擴張且費用維持，規模不大也能產生顯著營業槓桿。

市場可能高估

漲停容易使市場把「AI數位轉型」敘事等同於已落地成長，但前九月營收僅年增0.21%，9月還年減26.44%；生命、寵物、高球題材若沒有合約金額、非關係人客戶與現金流驗證，就仍是題材而非可估值獲利。

  • 觀察條件： 10月營收、Q3營業利益、其他利益及損失、關係人營收占比與實際現金流。
